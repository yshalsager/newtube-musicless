# Challenge solver bundle

The JavaScript MediaServiceCore runs in V8 to solve YouTube's signature (`s`) and throttling (`n`)
challenges, copied unchanged from `youtubeapi/src/main/assets/nsigsolver/` at `8e92399b`
(2026-09-29). `ChallengeSolver` runs it in JavaScriptCore (US-016).

| File | What | Licence |
|---|---|---|
| `yt.solver.core.js` | yt-dlp's EJS challenge solver (`jsc`), generated by https://github.com/yt-dlp/ejs | Unlicense |
| `meriyah-6.1.4.min.js` | meriyah 6.1.4, a JavaScript parser | ISC |
| `astring-1.9.0.min.js` | astring 1.9.0, a JavaScript code generator | MIT |
| `polyfill.js` | MediaServiceCore's shims (`URL`, `window`, `self`, `location`, `navigator`, `Object.hasOwn`) for a bare engine | MediaServiceCore's licence |

MediaServiceCore's `newtube.memo.js` (a V8 warm-up memo) is not used here.
